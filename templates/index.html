Frequently Asked Questions

Everything you need to know about layout preservation, tables, and regional language support.

Our backend uses PyMuPDF to extract text blocks along with their precise bounding box coordinates (x0, y0, x1, y1). The engine redacts the original text while preserving images, table borders, and background vectors, then re-inserts translated text into the exact same coordinates.
The app incorporates an automatic Unicode Font Manager that dynamically fetches Google Noto Sans TTF fonts (e.g. Noto Sans Devanagari, Noto Sans Gujarati, Noto Sans CJK) on-demand. This prevents broken characters or missing glyph boxes.
We feature an automatic font-size auto-scaling algorithm. If a translated phrase is longer, the engine incrementally reduces the font size to guarantee the text fits inside the original box without spilling over or overlapping adjacent content.
Documents up to 25MB are supported. Files are processed in memory and never stored permanently on third-party public storage servers.
